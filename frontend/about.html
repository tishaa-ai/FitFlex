About FitFlex

A final-year B.Tech major project in full-stack development and computer vision.

Our mission

Good coaching should not depend on where you live. FitFlex connects people with certified trainers online, builds diet plans from their own body numbers, and uses computer vision to give the kind of form feedback you would normally only get from a coach standing next to you.

Users and trainers have separate portals. Trainers set their weekly availability, confirm bookings, run group classes, write workout plans and share files with their clients.

Technology

  • FrontendHTML5, CSS3, JavaScript, Chart.js, Leaflet
  • BackendJava 17, Spring Boot, Spring Security + JWT, JPA
  • DatabaseMySQL 8 (H2 for quick runs)
  • Pose detectionPython, OpenCV, MediaPipe, NumPy
  • APIsSpoonacular, Google Places / OpenStreetMap, Jitsi Meet

Secure by design

BCrypt-hashed passwords, stateless JWT login and role-based access for users and trainers.

Works offline-first

Every external API has a fallback, so diet plans and gym search work even without API keys.

Built to learn from

Clean layered architecture: controllers, services, repositories and DTOs.
