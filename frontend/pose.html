AI pose detection

Your webcam + MediaPipe count reps and check your posture in real time.

1. See the body

MediaPipe Pose finds 33 landmarks (shoulders, elbows, hips, knees, ankles...) in every webcam frame.

2. Measure angles

For three points A-B-C we compute the angle at B with atan2, e.g. hip-knee-ankle = knee angle.

3. Count and coach

A rep counts when the angle goes past the "down" and back past the "up" threshold. Bad angles trigger feedback.

Run it on your computer

The detector is a Python program in the pose-detection/ folder (Python 3.10, 3.11 or 3.12).

cd pose-detection
uv venv --python 3.11 .venv
uv pip install --python .venv -r requirements.txt
.venv\Scripts\activate

# webcam, start with squats
python pose_detector.py --exercise squat

# upload the session to your FitFlex progress when you quit
python pose_detector.py --upload --email user@fitflex.com --password User@1234

No uv? Install Python 3.11 from python.org, then use py -3.11 -m venv .venv and pip install -r requirements.txt. Full steps are in pose-detection/README.md.

Keys: s squat · b bicep curl · p plank · r reset · q quit

Stand sideways to the camera, 2-3 m away, in good light, with your whole body in the frame. Angles are measured in 2D, so a limb pointing at the camera looks straighter than it is.
